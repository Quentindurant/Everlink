# Everlink

Outil interne de provisionnement et de bascule d'opérateur téléphonique, de SEWAN vers UNYC.

## Développement local

```bash
bun install
bun dev
```

## Déploiement

Déployé sur Prisma Compute. Voir `SPEC.md` §1 pour la stack, les variables d'environnement et la
procédure de déploiement.
