# Guides Speek joints aux mails de confirmation

Tout fichier PDF déposé dans ce dossier est **joint automatiquement** au mail de
confirmation des clients dont au moins un utilisateur possède un softphone (DOKO chez
Sewan, migré vers Speek chez UNYC).

- Un seul endroit à mettre à jour : remplacer le PDF ici met à jour tous les envois suivants.
- Le nom du fichier apparaît tel quel dans le mail : gardez un nom lisible par le client
  (`Guide utilisation Speek desktop.pdf` plutôt que `guide_v2_final_OK.pdf`).
- Ces fichiers sont versionnés : ils partent avec le déploiement, sans manipulation sur le VPS.
- Dossier vide = aucune pièce jointe, et la phrase qui les annonce disparaît du mail.
